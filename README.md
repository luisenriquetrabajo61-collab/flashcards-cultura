# 🧠 Cultura General - Flashcards Interactivas

¡Bienvenido a **Cultura General500 · Flashcards**! Una página web moderna, minimalista y ultraeficiente diseñada para estudiantes, opositores y entusiastas del conocimiento que buscan aprender o repasar temas de cultura general de forma dinámica y visual.

---

## 📸 Características Principales

*   **⚡ 500 Tarjetas Educativas:** Una base de datos masiva y local cargada al instante en el navegador.
*   **🗺️ Menú de Categorías Interactivo:** Navegación optimizada mediante un selector desplegable que permite filtrar tarjetas por temáticas (*Historia, Geografía, Ciencia, Deportes, Capitales, Elementos Químicos...*).
*   **🖼️ Fondos Dinámicos:** La interfaz adapta su fondo fotográfico automáticamente en alta resolución (vía Unsplash API) según la temática que el usuario decida estudiar, logrando una experiencia inmersiva.
*   **🔄 Modos de Navegación Flexibles:** Soporte para avance secuencial o modo aleatorio (*shuffle*) con reinicio de progreso instantáneo en memoria local.
*   **🌓 Interfaz Adaptable (Modo Oscuro/Claro):** Diseño adaptativo compatible con las preferencias del sistema del usuario.
*   **📬 Soporte de Contacto:** Formulario de soporte integrado de manera 100% segura mediante *FormSubmit*, protegiendo la privacidad del administrador.
*   **⚖️ Cumplimiento Legal Avanzado:** Ventana "Política de Privacidad" adaptada a las directrices de monetización de Google AdSense.

---

## 🛠️ Tecnologías Utilizadas

Este proyecto ha sido desarrollado bajo un paradigma estático moderno, maximizando el rendimiento sin dependencias pesadas:

*   **HTML5:** Estructura semántica avanzada y ventanas de diálogo nativas (`<dialog>`).
*   **CSS3 Pura:** Diseño responsivo (Mobile-First), variables nativas (`var(--x)`), soporte de temas y animaciones de volteo 3D por hardware (`preserve-3d`).
*   **JavaScript (Vanilla JS):** Motor lógico ligero y algoritmos de mezcla eficientes para la gestión del progreso y filtrado de datos.
*   **Vercel:** Plataforma de despliegue continuo y alojamiento en el edge.
